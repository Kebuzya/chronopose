# Протокол эксперимента и форма согласия участников (SCRUM-28)

## 1. Цель эксперимента
Сбор реальных видеоданных и данных с IMU-датчиков для обучения и валидации алгоритма классификации падений в системе ChronoPose (MVP к 01.12.2026).

## 2. Оборудование и условия
*   **Место проведения:** Помещение с безопасным покрытием (мат толщиной не менее 10 см).
*   **Камера:** Android-смартфон (IP Webcam), закрепленный на штативе или устойчивой поверхности.
*   **Носимый датчик:** Android-смартфон с приложением phyphox, закрепленный на поясе участника (имитация IMU).
*   **Исполнитель:** Ноутбук с запущенной системой ChronoPose (YOLO-pose + классификатор).

## 3. Сценарий проведения
1.  Участник надевает смартфон с IMU на пояс.
2.  Участник встает в размеченную зону перед камерой.
3.  По команде оператора участник выполняет базовые движения (ходьба, поворот), а затем имитирует падение на мат.
4.  Система фиксирует позу, классифицирует действие и отправляет сигнал.
5.  Эксперимент повторяется 3–5 раз для сбора достаточного объема данных. Длительность одного подхода — не более 5 минут.

## 4. Меры безопасности
*   Падение выполняется только на подготовленный мат.
*   Участник выполняет падение в контролируемой манере (без резких ударов).
*   В случае плохого самочувствия участник может прервать эксперимент в любой момент.
